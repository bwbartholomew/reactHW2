# React HW2 — ToDo List

## Запуск

```bash
npm install
npm start
```

Відкриється http://localhost:3000

## Що реалізовано

1. Дуже простий ToDo List (один компонент `App`, стан через `useState`).
2. `input` для тексту задачі та кнопка **Add TO DO**.
3. Після введення тексту й натискання кнопки задача додається до списку.
4. Список задач відмальовується в інтерфейсі (`todos.map`).
5. Показується кількість задач у списку (`todos.length`).
6. Додавання по клавіші **Enter** (подія `onKeyDown`).
